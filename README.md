# Gramáticas Libres de Contexto - Lenguajes y Autómatas

## Descripción

A partir de la gramática dada, se realizaron distintas actividades como:

- Identificación de variables, terminales y símbolo inicial.
- Generación y derivación de cadenas pertenecientes al lenguaje.
- Obtención de la cadena mínima posible.
- Resolución de ejercicios de verdadero o falso sobre derivaciones.
- Descripción en lenguaje natural del lenguaje generado por la gramática **L(G)**.
- Construcción del árbol de derivación para la cadena `aababa`.

El objetivo del trabajo fue comprender el funcionamiento de las gramáticas libres de contexto, las derivaciones y la generación de cadenas dentro de un lenguaje formal.
